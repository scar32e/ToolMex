¿Cómo generar una contraseña segura?

Esta herramienta usa crypto.getRandomValues, la API criptográficamente segura del navegador, para generar contraseñas verdaderamente aleatorias. Ninguna contraseña generada se envía ni se almacena en ningún servidor: todo ocurre en tu dispositivo.

Para mayor seguridad, se recomienda usar al menos 14 caracteres combinando mayúsculas, minúsculas, números y símbolos.

Preguntas Frecuentes

No. Se generan localmente en tu navegador y no se transmiten a ningún servidor.

Se recomienda un mínimo de 12 a 14 caracteres para cuentas importantes.
